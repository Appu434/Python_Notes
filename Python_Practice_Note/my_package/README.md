# my_package

This package, `my_package`, is designed to demonstrate the creation and usage of Python packages and modules. 

## Overview

`my_package` contains two modules:

- **module1**: This module includes a function `function1` that returns a greeting message.
- **module2**: This module includes a function `function2` that returns another greeting message.

## Installation

To use `my_package`, simply ensure that the package directory is in your Python path. You can then import the modules as follows:

```python
from my_package import module1, module2
```

## Usage

Here’s how you can use the functions provided by the modules:

```python
from my_package import module1, module2

print(module1.function1())  # Output: Hello from module1!
print(module2.function2())  # Output: Hello from module2!
```
